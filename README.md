# Dice Probability Visualizer

Live Demo: https://catan-dice-visualizer.vercel.app

## Project Overview

This project is a small interactive tool that visualizes dice roll probabilities used in strategy board games such as Catan.
It helps players understand which numbers appear most frequently when rolling two dice and allows users to simulate 1000 dice rolls to observe probability distribution in practice.

## Features

* Dice probability table for numbers 2 to 12
* Visual probability bar chart
* Highlighted high probability numbers (6 and 8)
* Dice roll simulator for 1000 rolls
* Real time simulation results display

## Tech Stack

* HTML
* CSS
* JavaScript
* GitHub
* Vercel

## Purpose

This project was created to explore probability visualization and how simple UI tools can improve strategic decision making in board games.

It also demonstrates basic front end development skills and product prototyping.
